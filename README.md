# 桌面宠物

一个不太负责任的饲养游戏。用纯 HTML / CSS / JavaScript 写的单文件小游戏。

## 玩法

1. 打开 `index.html`，点击「开始」
2. 选择要养的对象：易拉罐、面条，或者两个一起养（也可以两个都不选）
3. 在房间里通过「浇水」「施肥」照顾它，不同的选择会走向不同的结局
4. 解锁过的结局会保存在「结局图鉴」里，下次打开还在

## 运行

直接用浏览器打开 `index.html` 即可，不需要安装依赖或启动服务。

```bash
# 或者用 Python 起一个本地服务
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 说明

- 全部代码都在 `index.html` 一个文件里，无任何第三方依赖
- 结局图鉴进度通过浏览器 `localStorage` 保存
- 适配不同屏幕尺寸，支持移动端浏览
